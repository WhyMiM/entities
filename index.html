How to install

1. Unpack the downloaded ZIP file

2. Drag the unpacked data folder onto your client folder

3. Select "Replace the files in the destination" when prompted

4. In client Settings > Assets > Entities make sure default is selected

Extra stuff

I recommend cl_background_entities_color 9857893 (remember to save your current background) but these entities should look ok on most backgrounds.

bind mouse3 "toggle cl_text_entities 0 1" clicking middle mouse will toggle text on stuff like teleports/speedups/switches, most of the time you don't need to see them to understand parts. Adjust cl_text_entities_size to your liking.
